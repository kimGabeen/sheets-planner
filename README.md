# sheets-planner

구글 시트 하나로 쓰는 **개인 플래너**입니다. Google Apps Script로 만들었고,
`setup()`을 한 번 실행하면 시트·서식·수식·차트·트리거가 전부 자동으로 만들어집니다.
폰·아이패드·맥에서는 같은 시트를 저장소로 쓰는 **웹앱 화면**으로도 쓸 수 있습니다.

> 📸 스크린샷: [`docs/screenshots/`](docs/screenshots/) (추가 예정)

## 왜 만들었나

- **여러 기기에서 같이 쓰기** — 맥북(브라우저)에서는 한 주를 넓게 보고, 폰·아이패드(구글 시트 앱)에서는 오늘 할 일만 빠르게 체크하고 싶었습니다. 별도 앱 없이 구글 시트 하나면 모든 기기에서 동기화됩니다.
- **데이터 분석용 기록** — 할 일·습관·기분을 매일 "한 줄에 하나" 형태로 쌓아서, 나중에 CSV로 내려받아 pandas 등으로 바로 분석할 수 있게 했습니다.
- **외부 서비스 없이** — API 키나 서버 없이 Google Sheets + Google Calendar만 사용합니다.

## 주요 기능

- 📅 **구글 캘린더 연동** — 1시간마다 기본 캘린더 일정을 불러와 달력에 표시 (캘린더에서 지운 일정은 시트에서도 사라짐), 시트에서 바로 새 일정 추가 (중복 생성 방지)
- ✅ **요일별 할 일 10줄 + 시간 칸(선택)** — 체크 안 된 일은 시간순 → 시간 없는 순으로 위에, 체크한 일은 자동으로 아래로 (취소선 + 연한 배경), 그날 완료율을 ○◔◑◕● 원형으로 표시
- ↪ **못 한 일 자동 넘기기** — 매일 0시 전날 미완료를 다음 날 빈 줄로 복사, 전날 칸에는 "미완 →"으로 남기고 기록에는 `이월`로 저장 (설정에서 켜기/끄기)
- 🔁 **습관 트래커** — 설정 시트에 습관을 한 번만 적으면 위클리·오늘·먼슬리에 자동 반영
- 🙂 **기분 기록** — 1~5점(이모지) 드롭다운 + 한 줄 메모, 점수에 따라 칸 배경색이 바뀜
- 📱 **폰 전용 "오늘" 시트** — 3열 세로 화면, 위클리와 양방향 동기화
- 📊 **차트** — 요일별 완료 막대 + 주간 도넛, 일별 달성률 막대 + 기분 꺾은선
- 💾 **자동 기록** — 편집 즉시 + 매일 밤 23:50 기록 시트에 저장, 월요일 0시에 새 주로 초기화
- 🎨 **테마색 변경** — 설정 시트에서 색 코드 하나만 바꾸면 전체 색이 바뀜

## 웹앱 화면

구글 시트는 그대로 데이터 저장소로 두고, 매일 쓰는 화면은 Apps Script 웹앱(HtmlService)으로 만들었습니다.
아래 탭 4개로 이동하고, 폰은 1열, 아이패드·맥은 넓은 화면에 맞춰 2열·여러 칸으로 바뀝니다.

| 탭 | 내용 |
|---|---|
| **오늘** | 날짜 + 완료율 링, 오늘 일정 카드, 할 일(시간 꼬리표 + 줄바꿈, 누르면 시간·내용 편집, 시간순 자동 정렬, 넘어온 일), 습관 동그란 칩(편집 가능), 기분 5단계 + 한 줄 메모, 새 일정 추가 |
| **위클리** | 이번 주 목표·보상·확언, 꼭 끝낼 일, 요일 카드(가로 스크롤 ↔ 7칸 한 줄 토글), 카드를 누르면 **요일 상세 화면**, 시간표 편집, 습관 표 |
| **먼슬리** | 달력(일정 제목 1~2개 + "+N", 기분 점), 날짜를 누르면 **일정 추가·수정·삭제**(구글 캘린더에도 추가 토글), 이번 달 목표, 습관 달성률, 기분 그래프 |
| **타임라인** | 10분 칸을 눌러 카테고리 색칠(마우스는 끌어서 여러 칸), 오늘 카테고리별 합계 |

- **바로 반응하는 화면** — 체크하면 화면부터 바뀌고 저장은 `google.script.run`으로 뒤에서 합니다. 저장에 실패하면 작은 안내 문구를 띄우고 서버 값으로 되돌립니다.
- **시트와 양방향** — 웹앱의 API는 위클리 시트에 쓰고 기존 함수(정렬·오늘 시트 반영·기록 저장)를 그대로 재사용합니다. 시트에서 바꾼 내용은 앱으로 돌아올 때와 1분마다 다시 불러옵니다.
- **아이폰 대응** — `viewport-fit=cover` + safe-area 여백으로 노치·홈 바를 피하고, 탭바는 불투명 배경 + 내용 하단 여백으로 글자가 비치지 않게 했습니다. iframe 안에서 safe-area 값이 0이면 노치 있는 아이폰에 기본 여백을 넣습니다.
- **디자인** — 배경 `#FAF8F3`, 메인 `#2F5D50`, 포인트 `#E3EDE8`, Pretendard 글꼴, 그림자 없는 12px 둥근 카드, 44px 이상 터치 영역.
- **나만 접근** — "나로 실행 · 액세스: 나만" 설정이라 다른 사람은 열 수 없습니다.
- **먼슬리 일정** — 먼슬리 메모(한 줄에 일정 하나)로 저장돼 위클리·오늘 "일정"에 자동 표시되고, 할 일 10줄은 차지하지 않습니다. 토글을 켜면 기존 규칙대로 구글 캘린더에도 만들고, 일정 칸에는 한 번만 보이도록 연동 표시를 합니다.
- **고정 시간표** — 요일·시작·끝·이름과 학기 기간을 저장하면, 학기 중 매주 위클리·오늘 "일정"에 수업이 표시됩니다 (설정 시트 또는 웹앱에서 편집).
- **습관 편집** — 추가·삭제·이름 변경·순서 바꾸기(최대 10개). 위클리 체크가 습관을 따라 옮겨지고, 기록 시트의 지난 기록은 그대로 남습니다.
- 타임라인 카테고리 이름·색은 **설정** 시트에서 바꾸고, 기록은 **타임라인** 시트에 `날짜 | 시작 | 카테고리` 한 줄씩 쌓입니다.

## 시트 구성

| 시트 | 용도 | 주 사용 기기 |
|---|---|---|
| **위클리** | 주 목표·보상·확언, 꼭 끝낼 일 5개, 월~일 7칸(완료율/일정/할 일 10줄/합계/기분), 습관 트래커, 진행률 차트 | 맥북·아이패드 (가로) |
| **오늘** | 오늘 날짜 → 일정 → 할 일 → 습관 → 꼭 끝낼 일 → 기분 → 새 일정 추가 → 도구 → 넘어온 일 | 폰 (세로) |
| **먼슬리** | 연/월 드롭다운 달력(날짜+기분 이모지 / 캘린더 일정 / 내 메모), 이번 달 목표, 월간 습관 결과, 일별 차트 | 맥북 |
| **지난 주 보기** | 주차를 고르면 기록 시트에서 그 주 결과를 위클리 모양으로 불러옴 | 전체 |
| **기록** | `날짜 \| 구분 \| 항목 \| 완료여부 \| 값 \| 주차` 한 줄에 하나씩 쌓이는 분석용 데이터 | — |
| **타임라인** | 웹앱에서 칠한 10분 칸 `날짜 \| 시작 \| 카테고리` (분석용) | — |
| **설정** | 테마색, 못 한 일 자동 넘기기 켜기/끄기, 습관 목록, 자동 실행 상태, 타임라인 카테고리, 고정 시간표(학기 기간) | — |

```

                               │
                               ▼ (수식, 읽기 전용)
                 먼슬리 달력 · 위클리 일정 칸 · 오늘 일정

위클리 ◀──(양방향)──▶ 오늘
   │
   ▼ (편집 즉시 + 매일 23:50)
  기록 ──(수식)──▶ 먼슬리 습관·기분·차트 / 지난 주 보기
```

## 기술 스택

- **Google Apps Script** (V8 런타임, JavaScript), **HtmlService** 웹앱 (바닐라 JS, CSS)
- **Google Sheets** — 수식(`FILTER`, `LET`, `SPARKLINE`, `ARRAYFORMULA`), 조건부 서식, 임베디드 차트

- **clasp** — 로컬에서 코드 작성 후 Apps Script 프로젝트로 업로드

## 설계에서 신경 쓴 점

### 1. 모바일 앱 제약 대응
구글 시트 모바일 앱에서는 커스텀 메뉴, 그림 버튼, `alert`/`toast`/사이드바가 동작하지 않습니다.
- 수동 기능(지금 저장, 캘린더 새로고침, 일정 추가)은 모두 **체크박스 + 설치형 onEdit 트리거**로 실행하고, 실행 후 체크를 자동으로 해제합니다.
- 결과는 팝업 대신 **옆 셀에 글자로** 표시합니다 (`추가됨 ✓`, `오류: …`).
- 메뉴는 맥 브라우저용 보조 수단으로만 둡니다.
- 체크박스 크기는 글자 크기를 따라가므로 체크 칸의 글자 크기와 행 높이를 키워 손가락으로 누르기 쉽게 했습니다.
- 완료율 "원형 표시"는 셀마다 차트를 넣는 대신 `○◔◑◕●` 문자로 표현해 앱에서도 가볍게 보입니다.

### 2. 분석용 기록 시트 설계
- 넓은 표(날짜 × 항목)가 아니라 **긴 형태(long format)** 로 한 줄에 하나의 사실만 저장합니다. 습관이 바뀌거나 늘어나도 열 구조가 그대로라 CSV 분석이 쉽습니다.
- 같은 `날짜 + 구분` 묶음은 지우고 다시 써서 **중복 없이 덮어씁니다** (재실행해도 행이 늘어나지 않음).
- 시트를 통째로 지우는 코드가 없고, 필요한 행만 삭제합니다. `setup()`을 다시 실행해도 기록은 유지됩니다.
- `주차`는 그 주 월요일(`yyyy-MM-dd`) 글자로 저장해 정렬·필터가 간단합니다.

### 3. 트리거 중복 방지
- `installTriggers_()`는 이 프로젝트의 트리거를 먼저 모두 지우고 새로 만들기 때문에 `setup()`을 여러 번 실행해도 각 트리거가 1개씩만 존재합니다.
- 모든 트리거 함수는 `LockService`로 동시 실행을 막고, 오류는 설정 시트 "최근 오류" 칸에 남깁니다.
- 자정 트리거가 늦거나 빠져도 1시간마다 도는 캘린더 트리거가 "위클리가 지난 주에 머물러 있는지" 확인해 복구합니다.
- 일정 추가는 ① 체크 즉시 해제 ② 2분 캐시 ③ 같은 날 같은 제목·시간 일정 검사로 **같은 일정이 두 번 생기지 않게** 합니다.

### 4. 먼슬리 → 위클리 한 방향 데이터 흐름
- 캘린더 일정과 달력 메모는 숨김 시트 `_일정`에 모이고, 위클리·오늘의 "일정" 칸은 이를 **수식으로만 읽습니다** (회색 글씨, 읽기 전용).
- 위클리의 할 일은 먼슬리에 절대 올라가지 않습니다.
- 습관·기분은 위클리/오늘에서만 입력하고, 먼슬리는 기록 시트를 읽어 결과만 보여줍니다.

### 5. 할 일 정렬과 자동 넘기기
- 정렬은 체크·시간·내용을 바꿀 때마다 **설치형 onEdit**에서 실행되므로 폰 앱에서도 동작합니다. 순서가 그대로면 쓰지 않아 불필요한 쓰기를 줄였습니다.
- 시간 칸은 일반 텍스트 형식으로 두고 `14:00`·`1400`·`14시` 등을 `HH:mm`으로 정규화합니다. 시트의 시간 값은 1899년 기준이라 시간대 오차가 생길 수 있어 피했습니다.
- 넘기기는 `CARRY_DONE` 속성으로 **하루 한 번만** 실행됩니다. 자정 트리거가 늦어도 1시간마다 도는 트리거가 대신 처리하고, 일요일 미완료는 **표시·저장을 먼저 끝낸 뒤** 새 주 초기화를 진행해 데이터가 사라지지 않게 했습니다.
- 기록 시트에는 "미완 →", "↪" 같은 표시 기호를 떼고 순수한 항목 이름만 저장해 분석할 때 같은 일을 하나로 묶을 수 있습니다.

### 6. 레이아웃 변경에도 데이터 보존
- 시트 레이아웃 버전을 문서 속성에 저장하고, 버전이 바뀌면 예전 위치의 입력값을 읽어 새 위치로 옮긴 뒤 다시 그립니다 (예: 할 일에 시간 칸 추가).

### 7. 유지보수하기 쉬운 코드 구조
- 줄 수·시간·색·셀 위치는 모두 [`config.js`](src/config.js)에 모았습니다. 예: `TODO_ROWS`, `TRIGGER.NIGHTLY_HOUR`.
- 화면을 그리는 함수(`build*`)는 **입력 값을 건드리지 않고** 서식·수식만 다시 그리기 때문에, 테마색을 바꿀 때도 같은 함수를 재사용합니다.


Apps Script 서비스(SpreadsheetApp, CalendarApp 등)를 메모리 목업으로 바꿔 Node에서 실행합니다.
할 일 정렬, 오늘↔위클리 동기화, 못 한 일 넘기기(일요일→월요일 포함), 일정 추가 규칙, 중복 방지, 레이아웃 마이그레이션,
웹앱 API(할 일·습관·기분 저장 후 시트 반영, 먼슬리 집계, 타임라인 저장, 먼슬리 일정 추가·수정·삭제와 캘린더 연동,
고정 시간표 학기 기간 표시, 습관 편집 시 체크 이동·지난 기록 보존)를 검증합니다.

## 설치 방법 (clasp로 직접 써보기)

```bash
# 1. clasp 설치 및 로그인
npm install -g @google/clasp
clasp login

# 2. Apps Script API 켜기 (최초 1회)
#    https://script.google.com/home/usersettings 에서 "Google Apps Script API" 사용

# 3. 저장소 받기
git clone https://github.com/kimGabeen/sheets-planner.git
cd sheets-planner

# 4. 새 구글 시트 + 스크립트 만들기 → 코드 업로드
clasp create-script --type sheets --title "플래너" --rootDir src
#   (create가 src/appsscript.json을 기본값으로 덮어쓰면 git checkout src/appsscript.json)
clasp push --force
```

5. 만들어진 시트를 열고 **확장 프로그램 → Apps Script** → 함수 목록에서 `setup` 선택 → **실행**
6. 권한 요청 창에서 시트·캘린더 접근을 허용
7. **설정** 시트에서 습관 목록과 테마색을 입력

### 웹앱 배포

```bash
clasp create-deployment --description "웹앱"   # 처음 한 번 → 배포 ID 출력
echo "<배포 ID>" > .deployment-id               # .gitignore에 포함됨
npm run deploy                                  # 이후 코드 수정 시: push + 같은 주소로 재배포
```

`appsscript.json`의 `webapp` 설정(`USER_DEPLOYING`, `MYSELF`)으로 "나로 실행 · 나만 접근"으로 배포됩니다.
처음 열 때 권한 허용 창이 한 번 나옵니다.

> 기존 Apps Script 프로젝트에 연결하려면 `.clasp.json.example`을 `.clasp.json`으로 복사하고 `scriptId`를 채운 뒤 `clasp push` 하세요.

## 사용 팁

- **새 일정 추가 규칙** — 시작+끝: 그 시간대 일정 / 시작만: 종일 일정 + 제목 앞에 시간(예: `15:00 스터디`) / 둘 다 없음: 종일 일정. 끝시간이 시작보다 빠르면 "끝시간 확인"이 표시되고 추가되지 않습니다. 날짜를 비우면 오늘로 추가됩니다.
- **할 일 시간**은 `15:00`처럼 입력하면 됩니다 (`1500`, `15시`도 인식). 다음 날 할 일 칸이 꽉 차서 못 넘어간 일은 오늘 시트 맨 아래 "넘어온 일"에 보입니다.
- 수식 칸(일정, 완료율 등)을 실수로 지웠다면 메뉴 **플래너 → 처음 설정 / 다시 그리기**를 실행하면 복구됩니다 (입력 내용은 유지).
- 시간 트리거는 Google 정책상 지정 시각 ±15분 안에 실행됩니다.
- 트리거가 잘 돌고 있는지는 **설정** 시트의 "자동 실행 상태"에서 확인할 수 있습니다.
